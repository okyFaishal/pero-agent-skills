# CRDR-202609191530: Migrasi Protokol Riset Ilmiah dari Semantic Scholar MCP ke OpenAlex MCP & Penyelarasan Kredensial MCP

- **Status**: Diterima (Accepted)
- **Tanggal**: 2026-09-19
- **Pengambil Keputusan**: Architect & Engineering Team
- **Tipe Perubahan**: Tooling & Infrastructure Architecture Migration (Major)
- **Dokumen Terkait**: `AGENTS.md`, `README.md`, `.mcp.json`, `skills/scientific-research/SKILL.md`, `ADR-202609142226.md`

## 1. Konteks & Latar Belakang Masalah
Semantic Scholar memberlakukan kebijakan pembatasan API Key yang mewajibkan bukti instansi akademik (.edu) atau entitas nirlaba (non-profit), sehingga pengembang mandiri dan proyek personal sering kali ditolak. Selain itu, akses tanpa kunci dibatasi 100 kueri/5 menit dengan frekuensi pemblokiran Cloudflare (HTTP 429) yang tinggi.
Secara bersamaan, audit menemukan bahwa templat `.env.pero.example` masih menyisakan residu `BRAVE_API_KEY` yang sebenarnya sudah dipensiunkan pada ADR-202609142226.

## 2. Keputusan yang Diambil
1. Mengganti peladen `semantic-scholar` pada `.mcp.json` dengan `openalex` berbasis `@cyanheads/openalex-mcp-server`.
2. Mengonfigurasi `OPENALEX_MAILTO` untuk memanfaatkan *Polite Pool* (10 kueri/detik gratis tanpa syarat instansi).
3. Merapikan `.env.pero.example` dengan menghapus `BRAVE_API_KEY` dan menambahkan panduan mandiri lengkap cara mendapatkan setiap kunci API aktif (`CONTEXT7_API_KEY`, `TAVILY_API_KEY`, `STITCH_API_KEY`, `OPENALEX_MAILTO`/`KEY`).
4. Menyelaraskan seluruh 7 skill pemanggil dan pengawas riset akademik di Pero SDLC.
5. Memperbarui `docs/references/manifest.schema.json` untuk mengizinkan properti `$schema` dan format kanonikal DOI URL.

## 3. Alternatif yang Dipertimbangkan & Ditolak
| Alternatif | Alasan Penolakan |
|---|---|
| Tetap pada Semantic Scholar (Public unauthenticated) | Terlalu sering mengalami error 429 dan pemblokiran IP saat sub-agen bekerja paralel. |
| arXiv MCP murni | Cakupan terbatas pada Computer Science/AI/Fisika, tidak mencakup sistem rekayasa perangkat lunak multi-disiplin dan literatur umum. |
| Mempertahankan `BRAVE_API_KEY` di templat | Membingungkan pengguna karena `.mcp.json` tidak lagi mengaktifkan server `brave-search` (melanggar prinsip Anti-Slop). |

## 4. Konsekuensi Positif & Mitigasi Risiko
- **Positif**: Bebas hambatan akses personal, katalog 250M+ karya ilmiah, tautan open-access PDF langsung, hemat token 85-90% dengan `--select`, konfigurasi lingkungan 100% selaras dengan `.mcp.json`.
- **Mitigasi**: Kueri wajib menyertakan filter domain `Computer Science` saat meneliti arsitektur sistem software untuk menghindari hasil non-komputasi.
