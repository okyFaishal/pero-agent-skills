# ADR-202609142258: Pemasang Interaktif Bertingkat (Setup Wizard ala Vite) dengan Deteksi TTY & Isolasi Graphify

- **Tanggal**: 2026-09-14
- **Status**: Accepted
- **Pengambil Keputusan**: Pengguna & Antigravity (Sintesis Sidang LLM Council 5 Penasihat)
- **Kategori**: Architecture / Tooling
- **Relasi**: Melanjutkan ADR-202609142238

---

## 1. Konteks & Masalah (ELI5)
Pengguna menghendaki alur pemasangan proyek Pero di terminal yang interaktif dan ramah langkah-demi-langkah (seperti pada ekosistem React/Vite atau Next.js), di mana pengguna dituntun menentukan direktori target, adapter asisten AI (Cursor, Claude Code, Windsurf, Cline), dan pilihan perkakas opsional seperti peta graf kode (*Graphify*).

Sidang dewan 5 penasihat (*LLM Council*) mengidentifikasi risiko teknis kritis:
1. **Jebakan Pipa `curl | bash`**: Aliran pipa memakan saluran input standar (`stdin`). Jika skrip meminta input tanpa terminal fisik nyata, proses akan macet selamanya (*freeze/hang*) di server otomatis (CI/CD atau Docker).
2. **Kerapuhan Visual Bash (ANSI Slop)**: Meniru menu panah keyboard di Bash murni sangat rapuh di emulator terminal lawas atau Windows Git Bash.
3. **Pelanggaran Perlindungan Sistem (PEP 668)**: Memaksa instalasi Python global (`pip install graphify`) merusak integritas sistem operasi macOS/Linux.

Dewan menyepakati vonis: **Menerapkan arsitektur dua jalur (*Dual-Track Hybrid Installer*)**.

---

## 2. Faktor Pendorong Keputusan (*Decision Drivers*)
- **Pengalaman Pengembang Ramah Pemula (*Friendly Dev UX*)**: Memandu pengguna langkah demi langkah dengan pilihan bernomor sederhana (`1, 2, 3`) tanpa membingungkan.
- **Kekebalan Otomasi (*Zero Hang on Headless / CI*)**: Mendeteksi terminal fisik secara ketat (`[ -t 0 ]`, `[ -t 1 ]`, dan `/dev/tty`). Jika dieksekusi via pipa atau skrip mesin, skrip otomatis melewati wizard dan langsung menjalankan deteksi cerdas bawaan (*sensible defaults*).
- **Proteksi Ekosistem Host (Anti-PEP 668)**: Pemasangan Graphify hanya menggunakan ruang isolasi mandiri (`uv tool install` atau `pipx install`), dan mutlak menolak `pip` global.
- **Isolasi Kegagalan Non-Fatal**: Jika jaringan putus saat mengunduh Graphify, 30 modul skill Pero utama tetap terpasang 100% tanpa dibatalkan.

---

## 3. Opsi yang Dipertimbangkan
1. **Opsi A (Menolak Wizard - Tetap CLI Nir-Prompt Kaku)**:
   - *Kelebihan*: Sederhana dan cepat.
   - *Kekurangan*: Pengguna pemula merasa gamang karena tidak ada opsi interaktif di layar.
2. **Opsi B (Memaksa Wizard Penuh dengan Animasi Panah Keyboard TUI)**:
   - *Kelebihan*: Tampilan mirip aplikasi Node.js modern.
   - *Kekurangan*: Sangat rapuh di Bash, merusak skrip CI/CD, dan rawan mencetak karakter aneh (`^[[A`).
3. **Opsi C (Vonis Dewan Terpilih - Arsitektur Dua Jalur / Dual-Track Hybrid)**:
   - *Kelebihan*: Jika ada manusia di depan keyboard terminal (`[ -t 0 ] && [ -r /dev/tty ]`), wizard ramah bernomor muncul. Jika dijalankan oleh mesin/pipa/bendera `-y`, langsung meluncur cepat dalam 3 detik tanpa interupsi.

---

## 4. Keputusan Final & Rationale
Dipilih **Opsi C (Arsitektur Dua Jalur / Dual-Track Hybrid)** pada `install.sh` versi 3.2.0:
- **Dukungan Bendera Baru**:
  - `-i`, `--interactive`: Memaksa wizard interaktif (membaca via `/dev/tty`).
  - `-y`, `--yes`, `--non-interactive`: Memaksa mode otomatis tanpa prompt (bypass total).
  - `--with-graphify`: Memasang Graphify CLI terisolasi via `uv tool` / `pipx`.
- **Alur Wizard 4 Langkah**:
  1. Direktori target proyek (Enter langsung ke direktori aktif).
  2. Adapter asisten koding (Auto-detect / All / Kustom).
  3. Pilihan Graphify terisolasi (Lewati / Pasang via uv tool).
  4. Konfirmasi ringkasan sebelum eksekusi.
- **Pemberitahuan Informatif Bawaan**: Jika Graphify belum terpasang di mode default, skrip memberikan petunjuk ramah cara memasang mandiri via `uv tool install graphifyy`.

---

## 5. Konsekuensi Teknis
- **Dampak Positif**: Pengguna baru mendapatkan panduan visual yang jelas layaknya ekosistem modern, sementara pipeline CI/CD dan pengguna mahir tetap menikmati instalasi kilat 3 detik.
- **Strategi Mitigasi**: Penggunaan `/dev/tty` memastikan input tidak bertabrakan dengan aliran pipa `curl`, dan penanganan subshell menjamin kegagalan paket eksternal tidak pernah menggagalkan instalasi skill Pero.
